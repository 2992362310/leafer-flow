# 新架构基线与执行计划

状态：新设计基线，取代旧架构说明作为后续实施依据。本文描述目标与迁移进度，不表示目标已经全部实现。

## 目标与约束

- 面向可扩展的二维图形与流程图编辑器，渲染引擎为 Leafer，界面使用 Vue。
- 基础功能共享文档、命令、事务、历史和资源服务，不在界面、快捷键和 AI 中重复实现。
- 普通插件或组件接入不修改核心枚举、序列化分支和宿主面板清单。
- 新模型切换前以现有运行时为准；切换后以文档模型为唯一可写来源，不维护两套可写状态。
- 优先正确性与可验证性；暂不建设远程不可信插件沙箱、协同编辑或通用跨渲染引擎框架。

## 目标模块

| 模块          | 拥有的职责                                                                      | 禁止的依赖                   |
| ------------- | ------------------------------------------------------------------------------- | ---------------------------- |
| 文档模型      | 稳定节点 ID、节点类型和版本、父子层级、连线与端口、资源引用、文档设置、数据迁移 | Vue、Leafer 实例、浏览器存储 |
| 编辑器内核    | 命令、事务、历史、选择、注册表、插件状态与生命周期                              | 应用路由、市场策略、具体面板 |
| Leafer 适配层 | 模型投影、类型渲染、命中检测、坐标转换、手势预览与提交                          | 应用业务策略                 |
| Vue 界面层    | 工具栏、动态面板宿主、属性表单、停靠与会话状态                                  | 直接修改文档或渲染对象       |
| 功能模块      | 绘图、布局、模板、导出、AI，及各自的命令、配置、界面                            | 其他功能的私有实现           |
| 应用宿主      | 启动装配、路由、文件入口、存储适配与权限策略                                    | 绕过命令实现编辑行为         |

模块边界先于物理拆包。当前包可以承载多个内部模块，不为了目录整齐增加 workspace。

## 状态与修改契约

- 文档状态：节点、连线、层级、资源引用和文档设置，参与持久化和历史。
- 编辑会话：选择、悬停、工具、临时拖拽和加载状态，随编辑会话释放。
- 用户偏好：面板布局、主题和个人默认值，由宿主偏好存储持有。
- 插件临时状态：请求、监听、动画和缓存，由插件实例持有并释放。
- 修改链路为：交互入口 -> 命令校验 -> 短事务 -> 文档变更 -> 渲染、历史与自动保存。
- 网络请求、文件读取和布局计算在事务外完成；拖拽允许临时预览，结束时提交一次。
- 目标事务支持失败回滚。迁移初期的历史批处理不等于原子事务，不承诺回滚。

## 扩展契约

- 插件声明命名空间 ID、版本、宿主兼容版本及真实可用的依赖；宿主负责状态、激活去重、失败清理和销毁。
- 所有注册与事件订阅提供释放句柄，插件上下文提供统一资源托管；注册表变更通知界面。
- 界面扩展声明宿主位置、显隐条件、组件与命令，不增加硬编码面板 ID。
- 画布组件声明类型、版本、默认数据、校验、渲染、属性、迁移和资源引用；缺失类型用占位节点保留原始数据。
- 普通扩展使用受控服务；需要底层渲染能力的适配器使用显式内部接口，不把全部 Editor 作为通用插件 API。
- 第一阶段插件静态装配且可信；capabilities 描述不构成安全隔离。

## 资源契约

- 应用静态资源、插件自带资源、文档资源分别管理。
- 文档资源通过稳定 assetId 引用；Blob URL 只是可释放的运行时缓存，不作为持久化地址。
- 资源服务负责校验、去重、存储、解析、缩略图与便携导出；本地存储由 IndexedDB 适配器实现。
- 回收时考虑文档、历史和剪贴板引用；删除节点不能立即删除资源。
- 文件格式需要明确资源嵌入或打包方式、schemaVersion 和迁移策略。

## 验证规则

- 每个阶段先跑可反驳当前假设的最小行为检查，再运行受影响包的类型检查。
- P1 使用 Node 内置测试运行器加载实际 TypeScript 实现，隔离 Leafer/DOM/存储边界，不新增测试框架依赖。
- 涉及保存恢复、连接线、历史和插件资源的变更必须有针对性行为检查。
- 阶段结束执行包边界、lint 错误检查和完整类型检查；跨包或入口调整再执行生产构建。
- 静态和内存检查不替代浏览器交互验收；未执行的流程明确记录。
